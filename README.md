# 簪子解谜 · 网页版

参考短视频玩法制作的圆环抽簪解谜游戏，纯前端实现，无构建步骤、无依赖。所有簪子、圆环与背景图形均由 Canvas 2D 代码实时绘制，美术为原创。

## 玩法

簪子插在可旋转的圆环上，分为若干叠放层。上层簪子会遮住角度相近的下层簪子。拖动圆环，把可取的簪子转到顶部缺口处点击抽出，送入底部收纳槽；同色三支进入收纳槽即合成消除。清空整个圆环即通关，收纳槽塞满且无法合成则失败。

每关生成后都会先用求解器验证可解，不会出现死局。

## 运行

直接用浏览器打开 `index.html` 即可，无需服务器。

## 自动解牌

点击「自动解牌通关」后，求解器从当前盘面重新规划路径，逐步旋转圆环并抽出簪子，直到清空。

## 手指轨迹模拟

- 「● 开始录制」在画布上真实操作，记录每个指针事件。
- 「导出轨迹」保存为 JSON。
- 「上传手指轨迹 JSON」+「▶ 回放手指」按原时间轴重放。

轨迹格式：

```json
[{ "t": 0, "type": "down", "x": 0.5, "y": 0.4 }, { "t": 120, "type": "move", "x": 0.55, "y": 0.42 }, { "t": 300, "type": "up", "x": 0.55, "y": 0.42 }]
```

`t` 为毫秒，`x`/`y` 为相对画布的 0–1 坐标。
